# CI/CD 流水线项目 - 常见问题
## 一、Jenkins 流水线核心问题
### 问题 1：流水线执行失败/阶段跳过未推送部署
#### 现象
Jenkins 构建终止，镜像推送、K3s 部署阶段直接跳过，构建状态失败。
#### 可能原因
- 代码语法/依赖异常导致冒烟测试不通过
- 代码拉取失败、Git 仓库权限异常
- 流水线前置阶段执行报错触发中断
#### 解决方案
1. 查看失败阶段日志，定位具体报错点
2. 修复代码语法/依赖问题，重新提交触发构建
3. 校验 Git 凭证、文件路径配置正确性
#### 经验总结 / 复盘
Jenkins 声明式流水线具备阶段中断机制，**前置质量门禁失败会自动拦截后续流程**，排错优先查看最近失败阶段的原始日志，无需排查全链路。

### 问题 2：K3s 集群权限异常，自动回滚命令执行失败
#### 现象
流水线部署阶段，执行容器自动回滚命令 `kubectl rollout undo deployment` 报错；不加 sudo 提示找不到 kubectl / 无权限访问 K3s 集群，加 sudo 命令直接执行失败。
#### 可能原因
- Jenkins 容器内未配置 K3s 访问凭证，无集群操作权限
- 容器用户为普通权限，无 kubectl 命令执行权限
- sudo 权限受限，禁止执行 kubectl 高危命令
#### 解决方案
1. 在 Jenkins 中配置 K3s 集群的 kubeconfig 凭证
2. 流水线中挂载凭证，配置环境变量指向合法 kubeconfig
3. 无需 sudo，直接通过凭证授权执行回滚命令
#### 经验总结 / 复盘
容器化 CI/CD 操作 K8s/K3s 集群**禁止依赖 sudo 提权**，标准方案是通过专用 kubeconfig 凭证授权；权限配置遵循最小原则，既保证流水线功能，又规避集群安全风险。


## 二、冒烟测试质量门禁问题
### 问题 1：冒烟测试失败触发构建拦截
#### 现象
镜像构建阶段执行 pytest 报错，`ModuleNotFoundError`/服务启动失败，构建终止。
#### 可能原因
- `requirements.txt` 缺失项目依赖包
- 代码存在语法错误、模块导入错误
- 工作目录配置错误，脚本无法找到对应文件
#### 解决方案
1. 补全依赖并更新依赖清单
2. 本地执行冒烟测试，修复代码逻辑
3. 校验 Dockerfile 工作目录与文件拷贝配置
#### 经验总结 / 复盘
冒烟测试是**部署前最后一道质量门禁**，本地提前验证可避免流水线构建失败，大幅提升交付效率。

## 三、Docker 镜像构建与推送问题
### 问题 1：镜像构建/推送至仓库失败
#### 现象
镜像构建中断，或推送至私有仓库时报权限/网络错误。
#### 可能原因
- Dockerfile 语法错误、命令执行异常
- 镜像仓库登录凭证错误/权限不足
- 网络不通，无法连接镜像仓库
#### 解决方案
1. 本地测试 `docker build` 验证镜像构建
2. 核对仓库地址、账号密码等配置
3. 测试 Jenkins 节点与镜像仓库网络连通性
#### 经验总结 / 复盘
镜像构建排错遵循**本地优先原则**，本地验证通过后再提交流水线，减少云端构建调试成本。

## 四、K3s 部署与自动回滚问题
### 问题 1：K3s 部署超时/健康检查失败未回滚
#### 现象
滚动更新卡住，服务不可用，未触发预设的自动回滚逻辑。
#### 可能原因
- 集群资源不足，容器无法启动
- 健康检查超时时间配置不合理
- 回滚命令权限不足/执行异常
#### 解决方案
1. 检查 K3s 集群状态与资源使用率
2. 调整健康检查探测间隔与超时参数
3. 手动测试 `kubectl rollout undo` 命令可用性
#### 经验总结 / 复盘
云原生部署的故障自愈**依赖权限+配置双重保障**，核心命令必须提前手动验证，确保异常时可自动兜底。
